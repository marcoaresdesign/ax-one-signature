Fond transparent: la signature n'a aucun fond, elle prend donc la couleur de l'arrière-plan du logiciel où le courriel est ouvert. Le texte s'adapte tout seul: foncé en mode clair, pâle en mode sombre. L'orange, les icônes et le bouton restent visibles peu importe l'arrière-plan. Sur les clients qui gèrent le mode sombre comme Apple Mail, l'adaptation du texte est automatique, et Gmail applique en général sa propre inversion de couleurs en thème foncé.

Comment installer ta signature

Gmail (ordinateur)
  1. Clique sur Copier ma signature ci-dessus.
  2. Dans Gmail, va dans Paramètres (roue dentée) > Voir tous les paramètres.
  3. Onglet Général, descends jusqu'à Signature, clique Créer.
  4. Clique dans la zone de texte de la signature et fais Coller (Cmd+V / Ctrl+V).
  5. Descends et clique Enregistrer les modifications. C'est fait.
Apple Mail (Mac)
  1. Ouvre Mail > Réglages > Signatures et crée une nouvelle signature (n'importe quel texte).
  2. Décoche « Toujours utiliser ma police par défaut ».
  3. Clique Voir le code HTML ci-dessus, copie tout le code.
  4. Méthode simple: colle d'abord la signature (bouton Copier) directement dans la zone de signature. Si le rendu n'est pas parfait, utilise la méthode fichier .html décrite dans la note ci-dessous.
  5. Ferme les réglages. Sur Apple Mail, la carte passe automatiquement en foncé en dark mode.
Outlook (ordinateur et web)
  1. Clique Copier ma signature.
  2. Outlook Web: Paramètres > Courrier > Composer et répondre > Signature, puis colle.
  3. Outlook bureau (Windows): Fichier > Options > Courrier > Signatures, crée une signature et colle.
  4. Enregistre. Note: Outlook classique (Windows) peut légèrement arrondir moins les coins, mais tout le contenu et les couleurs restent corrects.
Mobile (iPhone / Android)
  1. Le plus simple: configure ta signature sur ordinateur d'abord (Gmail, Outlook). Elle se synchronise automatiquement sur l'app mobile du même compte.
  2. La signature est en tableaux responsives: elle s'adapte à la largeur de l'écran, aucune coupure sur mobile.
Méthode fichier .html (rendu parfait garanti, Apple Mail + Outlook): Clique « Voir le code HTML », copie le code, colle-le dans un fichier texte que tu enregistres avec l'extension .html. Ouvre ce fichier dans un navigateur, sélectionne toute la signature affichée, copie, puis colle dans la zone de signature de ton client courriel. Cette méthode préserve le dark mode automatique.
